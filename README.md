## Development Workflow

Branch → Code → Commit → Push → Pull Request → Review → Merge

1. **Branch** – Create a feature branch off `main` for new work
2. **Code** – Make changes in `app.py` or other project files
3. **Commit** – Save changes with clear, descriptive commit messages
4. **Push** – Upload the branch to GitHub
5. **Pull Request** – Open a PR from the feature branch into `main`
6. **Review** – Check the diff for errors before merging
7. **Merge** – Combine the changes into `main`
